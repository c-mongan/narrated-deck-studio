# Creative direction: the human-beating bar

The target is not “looks professional.” The target is a deck a top creative director would want to put their name on.

## Before slide code

Generate at least **three genuinely different creative territories**. Each needs:

- one-sentence big idea;
- visual metaphor or source material;
- typography direction;
- palette rationale;
- image/illustration direction;
- composition grammar;
- signature moment(s);
- why this could only belong to this topic/audience;
- risks / ways it could become gimmicky.

Do not create three color variants of one layout.

## Selection

Score concepts on topic specificity, memorability, audience fit, visual range, feasibility, and evidence compatibility. Select one and state why the other two lost.

## Hero moments

Design 2–4 slides as memorable “hero moments” where the deck earns disproportionate visual attention. Other slides should support them; not every slide should shout.

## Composition

Avoid template repetition. Across a deck, deliberately vary scale and negative space while preserving system coherence. Use asymmetry, edge crops, full-bleed imagery, editorial grids, diagrammatic pages, quiet pages, and data pages only when the story benefits.

## Image direction

For every non-user image decide separately: documentary/source image, licensed/search image, generated image, diagram, or no image. Never let “the deck is AI-styled” automatically force generated images. For verifiable people/places/products, prefer source-grounded imagery unless the creative treatment is intentionally non-documentary.

## Anti-template test

Ask: if all logos and nouns were removed, could this deck be mistaken for a generic AI SaaS pitch? If yes, fail it.
