# Anti-slop copy standard

The deck must not sound like a generic LLM or consulting parody.

## Flag by default

- “unlock” / “unlocking potential”
- “revolutionize”
- “transformative”
- “game-changer”
- “seamless” when it does not describe an observable integration property
- “leverage” used as a vague verb
- “future-ready”
- “ever-evolving landscape”
- “not just X, but Y” rhetorical filler
- unsupported superlatives
- empty words such as “robust”, “powerful”, “innovative”, “holistic” without evidence

## Rewrite test

Ask: “Could this sentence appear unchanged in a deck about a completely different company?”

If yes, it is probably too generic.

Prefer concrete mechanism + outcome:

Bad: “Unlock transformative insights with our powerful AI platform.”
Good: “The model groups recurring build failures and links each cluster to the commits most likely to have introduced it.”
